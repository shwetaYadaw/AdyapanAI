PROBLEM IDENTIFIED:
- Seed API reported 11 coding problems were created successfully
- But when opening a topic (e.g., "Arrays"), the page showed "0 Problems"
- Message: "No problems found for this topic yet. Check back soon!"

ROOT CAUSE:
In CodingTopicPage.tsx (line 80), the filtering logic was:
```typescript
const topicQuestions = (questions ?? []).filter((q) =>
  q.topics.some((t: string) => t.toLowerCase() === topicKey)
);
```

PROBLEM:
1. The `q.topics` field is a STRING (e.g., "Arrays"), NOT an array
2. Calling `.some()` on a string doesn't work - it throws an error
3. The filter returns empty array because of this error
4. Frontend shows "0 Problems" and "No problems found"

SOLUTION APPLIED:
Updated the filtering logic to handle both string and array formats:

```typescript
const topicQuestions = (questions ?? []).filter((q) => {
  // Handle both string and array formats for topics
  const topicsList = Array.isArray(q.topics) 
    ? q.topics 
    : (typeof q.topics === 'string' ? [q.topics] : []);
  return topicsList.some((t: string) => t.toLowerCase().replace(/\s+/g, '-') === topicKey);
});
```

WHAT THIS DOES:
1. Checks if topics is already an array - use as-is
2. If it's a string - convert to array with [q.topics]
3. If it's neither - use empty array []
4. Then properly filter by comparing lowercase versions with topic key
5. Handles spaces correctly (e.g., "Binary Search" → "binary-search")
