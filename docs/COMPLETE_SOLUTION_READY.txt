================================================================================
TROUBLESHOOTING
================================================================================

Problem: Script doesn't run
──────────────────────────
Solution:
  npm install -g ts-node typescript
  Or use: npx tsx scripts/seed-all-topics.ts

Problem: Database connection error
──────────────────────────────────
Solution:
  Check .env file has DATABASE_URL
  Verify PostgreSQL is running
  Check database credentials

Problem: "Duplicate entry" error
────────────────────────────────
Solution: Normal! Script skips duplicates
  Just means problem already exists
  Script will report "Already existed: X"

Problem: Still seeing "0 Problems" in browser
──────────────────────────────────────────────
Solution:
  Hard refresh: Ctrl+Shift+R
  Clear browser cache: Ctrl+Shift+Delete
  Wait 5 seconds for page to load
  Check browser console (F12) for errors

Problem: Some problems missing
─────────────────────────────
Solution:
  Check script output for errors
  Some might have failed (check logs)
  Can re-run script to retry failed ones
