PROBLEM STRUCTURE (Example):
================================================================================

Title: "Best Time to Buy and Sell Stock"
Difficulty: easy
Statement: "You are given an array prices where prices[i] is the price on 
          ith day. You want to maximize profit by choosing one day to buy 
          and a different day in the future to sell."

Input Format: "Line 1: n (number of days), Line 2: n space-separated integers"
Output Format: "Single integer (maximum profit)"
Constraints: "1 <= n <= 300, 0 <= prices[i] <= 10000"

Starter Code:
    def maxProfit(prices):
        # Write your solution here
        pass
    
    # Example:
    prices = [7, 1, 5, 3, 6, 4]
    print(maxProfit(prices))  # Output: 5

Reference Solution:
    def maxProfit(prices):
        min_price = float('inf')
        max_profit = 0
        for price in prices:
            min_price = min(min_price, price)
            max_profit = max(max_profit, price - min_price)
        return max_profit
