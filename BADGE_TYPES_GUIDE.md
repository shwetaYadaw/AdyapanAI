## Badge Design Specifications

### Circle Design
```
Diameter:       100px (desktop)
                80px (tablet)
                70px (mobile)

Shadow:         0 4px 12px rgba(0,0,0,0.15)

Border Radius:  50% (perfect circle)

Background:     Gradient from badge type color

Hover Shadow:   0 8px 16px rgba(0,0,0,0.25)
```

### Adyapan Logo
```
Position:       Top center
Font:           Bold, 14px
Color:          Matches badge type (60% opacity)
Text:           "ady."
Letter Spacing: 1px
```

### Icon
```
Position:       Center
Font Size:      48px (desktop)
                36px (tablet)
                32px (mobile)

Shadow:         0 2px 4px rgba(0,0,0,0.2)
Color:          White with shadow
```

```

Border:         2px white

Font:           Bold, 14px white
```
