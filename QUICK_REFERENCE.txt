COMMON ERRORS & FIXES:
════════════════════════════════════════════════════════════════

Error: "Failed to fetch dynamically imported module"
  → Backend not running
  → Fix: yarn dev:backend in Terminal 1

Error: "Cannot connect to database"
  → DATABASE_URL invalid or missing in .env
  → Fix: Check .env file

Error: "Port already in use"
  → Something else using port 5000 or 3000
  → Fix: Kill process (see above)

Error: "Cannot find module"
  → Dependencies not installed
  → Fix: yarn install

Error: Vite errors
  → Frontend not starting
  → Fix: Check Terminal 2, look for error message
