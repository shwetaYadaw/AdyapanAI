   - Concept: Net calculation

   - Time: O(n log n)
   - Concept: Optimization via sorting

3. Jump Game - Reachability + greedy tracking
   - Time: O(n)
   - Concept: Boundary tracking

4. Jump Game II - Minimum jumps + greedy levels
   - Time: O(n)
   - Concept: Level-by-level greedy

5. Minimum Cost Coins - Resource selection
   - Time: O(n log n)
   - Concept: Maximum value free items

6. Minimum Arrows to Burst Balloons - Interval greedy
   - Time: O(n log n)
   - Concept: Rightmost selection strategy

7. Minimum Absolute Sum Difference - Binary search optimization
   - Time: O(n log n)
   - Concept: Optimal replacement search

8. Maximum Equal Sum Three Stacks - Multi-pointer technique
   - Time: O(n1+n2+n3)
   - Concept: Synchronized traversal

  - Time: O(n² log n)
