COMMUNICATION FLOW:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    What happens when you use the app:
    
    
    BROWSER (http://localhost:3000)
         ↓ 1. You click on something
         ↓
    FRONTEND (React/Vite)
         ↓ 2. React makes an API call
         ↓    (like /api/problems)
         ↓
    VITE PROXY
         ↓ 3. Routes request to
         ↓    http://localhost:5000/api/problems
         ↓
    BACKEND API (Express.js)
         ↓ 4. Backend receives request
         ↓    Queries database
         ↓    Returns JSON data
         ↓
    FRONTEND
         ↓ 5. Frontend receives data
         ↓    Updates UI
         ↓
    BROWSER
         ↓ 6. You see the results
         ✅ Success!
    
    
    ⚠️  IF BACKEND NOT RUNNING (port 5000):
        Frontend can't reach it → All API calls fail → Error!

TROUBLESHOOTING QUICK FIXES:

    ────────────────────────    ─────────────────────────────────────

                                taskkill /PID <PID> /F

                                taskkill /PID <PID> /F

    Dependencies broken         Remove node_modules, reinstall
    
    Still getting error         .\diagnose-error.ps1
                                (runs diagnostic)
    
    Backend won't start         Check .env file
                                Check DATABASE_URL
    
    Frontend won't load         Keep backend running first!
                                Never close terminal 1
